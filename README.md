# 🏊‍♂️ Catraca Legacy - Sistema de Acesso

Projeto de estudo prático focado na construção de um sistema de controle de acesso (catraca) para uma academia de natação, utilizando Arquitetura Orientada a Eventos.

## 🛠️ Stack Tecnológica
* **Linguagem:** Java 21
* **Framework:** Spring Boot
* **Mensageria:** Apache Kafka
* **Banco de Dados:** PostgreSQL

## 📝 Diário de Bordo (Passo a Passo)

### Passo 1: Setup Inicial da Aplicação
* Estruturação do projeto gerada via Spring Initializr.
* **Dependências principais adicionadas:** Spring Web, Spring Data JPA, PostgreSQL Driver, Spring for Apache Kafka, Lombok e Spring Boot DevTools.
* Projeto importado e configurado na IDE.
